# 🕷️ Pomodoro Spiderman

A pixel-art Pomodoro timer desktop application
built with Electron and JavaScript.

## Features

- ⏱️ 25-minute work timer
- ☕ 5-minute break
- ▶️ Start
- ⏸️ Pause
- 🔄 Reset
- 🔊 Sound effects
- 🎵 Background music
- 🕷️ Spider-Man pixel art UI

## Technologies

- HTML
- CSS
- JavaScript
- Electron

## Installation

npm install

## Run

npm start
